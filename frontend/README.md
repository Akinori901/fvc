# Frontend — できること

React 19 + TypeScript + Material-UI で構築されたSPAです。
ログイン後、サイドバーナビゲーションから各機能にアクセスできます。

---

## 機能一覧

### ダッシュボード（`/`）

起動直後に表示されるホーム画面。

- 登録銘柄数・算出履歴件数のサマリーカード
- 「適正株価を算出する」「銘柄一覧を見る」クイックアクションボタン
- 直近5件の算出結果プレビュー（銘柄・適正株価・現在株価・評価ゾーン）
- 直近3件のデータ同期ログ（同期種別・ステータス・日時）

---

### 適正株価算出（`/valuations/calculate`）

このアプリのメイン機能。

1. **銘柄選択**：オートコンプリート検索で銘柄コード・銘柄名から素早く選択
2. **財務データ確認**：選択した銘柄の最新BPS・ROE・EPS を自動表示
3. **成長率入力**：期待する成長率（%）を入力
4. **現在株価入力**：自動でDBの最新株価を補完（手動上書き可）
5. **算出ボタン**で以下の結果を取得：
   - 適正PBR・適正株価
   - 現在株価との乖離率（割引率）
   - 評価ゾーンバッジ（6段階）
   - **価格レンジバー**：5ゾーンを色分けし、現在株価の位置をビジュアル表示

算出結果は自動保存され、算出履歴から後から参照できます。

---

### 算出履歴（`/valuations`）

過去に算出した全結果をカード形式で一覧表示。

- 銘柄名・証券コード
- 適正株価・現在株価・成長率
- 適正PBR
- 評価ゾーンバッジ
- カードクリックで詳細画面へ遷移

#### 算出詳細（`/valuations/:id`）

個別の算出結果を詳細表示。

- 結果サマリーカード（乖離率・評価ゾーン・BPS等）
- 価格レンジバー

---

### 銘柄一覧（`/stocks`）

登録済み銘柄の管理とスクリーニング。

#### 通常一覧モード

- DataGrid による銘柄一覧（25/50/100件ページネーション）
- 証券コード・銘柄名・市場・業種・最新株価
- 行クリックで銘柄詳細へ遷移
- データ同期ボタン（J-Quants または yfinance からデータを取得）

#### スクリーニングモード

- 成長率スライダー（0〜30%）を基準に適正株価を動的計算
- 割安度フィルター（最低乖離率で絞り込み）
- 業種フィルター
- 条件に合致した銘柄を一覧表示

#### 銘柄詳細（`/stocks/:code`）

3タブ構成で銘柄情報を詳細確認。

| タブ | 内容 |
|------|------|
| 財務データ | 年度別BPS・EPS・ROE・純資産・発行済株式数 |
| 株価チャート | Recharts による時系列株価グラフ |
| 算出履歴 | この銘柄に対して過去に実施した全算出結果 |

ヘッダーには最新株価・BPS・ROE・PBR のサマリーカードを表示。

---

### ウォッチリスト（`/watchlist`）

気になる銘柄を登録してリスト管理。

- 銘柄コード + メモ で登録
- 登録済み銘柄の一覧表示（銘柄名・コード・メモ）
- 削除機能

---

### ポートフォリオ（`/portfolio`）

実際の保有株を口座種別ごとに管理。

**対応口座種別**：

| 種別 | 説明 |
|------|------|
| NISA 成長投資枠 | NISA（成長投資） |
| NISA つみたて投資枠 | NISA（積立） |
| 特定口座 | 源泉徴収あり/なし |
| 一般口座 | 一般口座 |
| 米国証券口座 | 海外証券口座（米国株向け） |

各ポートフォリオアイテムに記録できる情報：

- 銘柄コード・銘柄名
- 口座種別
- 保有数量
- 取得単価
- 購入日
- メモ

口座種別でフィルタリング、追加・編集・削除ダイアログ付き。

---

### 設定（`/settings`）

外部データプロバイダーの API 設定を管理。

- **J-Quants API**：有効/無効切り替え・APIキー入力・プラン選択
- プラン別機能差異表（free / light / standard / premium）

## 評価ゾーン（6段階）

適正株価との乖離率（割引率）をもとに6段階で評価します。

| ゾーン | 乖離率 | 色 |
|--------|--------|-----|
| 超割安 | +30% 以上 | 濃緑 |
| 割安 | +10% 〜 +30% | 緑 |
| 適正 | -10% 〜 +10% | 黄 |
| 割高 | -30% 〜 -10% | オレンジ |
| 危険 | -30% 未満 | 赤 |

> 乖離率 = (適正株価 − 現在株価) / 適正株価

| Vite 6 | ビルドツール |

## ローカル開発

Docker を使わずフロントエンド単体で開発する場合：

```bash
cd frontend
npm install

# 開発サーバー起動（http://localhost:3000）
npm run dev

# プロダクションビルド
npm run build

# テスト実行
npm test

# テスト（ウォッチモード）
npm run test:watch

# Lint チェック
npm run lint
```

> Docker 経由での起動は `make up`（リポジトリTOP の README 参照）。
